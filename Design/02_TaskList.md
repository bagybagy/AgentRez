# Rez Infinite Area X 再現

## 仕様対応・実装タスクリスト（確定版）

---

## Phase 0: プロジェクト初期化（仕様 11 対応）

* [ ] Unity プロジェクトを作成する
* [ ] URP を有効化する
* [ ] VFX Graph を有効化する
* [ ] 固定フレームレートを設定する
* [ ] 空のシーンを作成する

**禁止**

* 可変フレームレート前提の処理を作らない

---

## Phase 1: 音楽・拍基準システム（仕様 6 対応／最重要）

### 1.1 BGM 再生

* [ ] 単一楽曲を AudioSource で再生する
* [ ] 再生開始が体験開始と一致するようにする
* [ ] 再生中に停止・切替を行わない

---

### 1.2 拍情報の取得

* [ ] 楽曲から BPM を取得または設定する
* [ ] 拍開始時刻を算出できるようにする
* [ ] 小節開始時刻を算出できるようにする

※ 解析方法（事前／実行時）は問わない

---

### 1.3 拍イベント発行

* [ ] 拍開始時に BeatEvent を発行する
* [ ] BeatEvent に以下の情報を含める

  * 拍開始時刻
  * 拍の長さ
  * 次の拍開始時刻
* [ ] 小節開始時に MeasureEvent を発行する

**重要**

* 拍イベントは「通知」ではなく「時刻取得のための基準」とする

**禁止**

* 拍イベントを待ってから命中処理を行わない

---

### 1.4 拍揺れ非対応（仕様明示）

* [ ] 拍の揺れ、テンポ変化、転調への対応は行わない
* [ ] 拍情報は常に「次に到来する拍」を正とする

---

## Phase 2: プレイヤー（視点）システム（仕様 4 対応）

### 2.1 プレイヤー定義

* [ ] プレイヤーをカメラとして定義する
* [ ] キャラクターモデルを作成しない

---

### 2.2 視点操作

* [ ] 視点を全方向に回転可能にする
* [ ] 回転速度に上限を設ける
* [ ] 急激な回転入力は補間する

---

### 2.3 移動（最小構成）

* [ ] 初期実装では移動入力を実装しない
* [ ] 必要な場合のみ、低速・一定速度移動を許可する
* [ ] 移動は攻略条件・成功条件に影響させない

**禁止**

* レール移動
* 高速移動
* 回避アクション

---

## Phase 3: 空間構築（仕様 3 / 9 対応）

### 3.1 空間構造

* [ ] 有限な 3D ボックス空間を作成する
* [ ] 壁・床・天井を明示的に表示しない
* [ ] 境界は不可視とする

---

### 3.2 背景表現

* [ ] 背景はポイントクラウド／粒子のみで構成する
* [ ] 通常メッシュ背景を使用しない

---

### 3.3 拍同期背景変化

* [ ] 拍イベントで以下を変化させる

  * 粒子発光強度
  * 粒子密度
  * 粒子配置ノイズ

**禁止**

* 時間経過のみで背景を変化させない

---

## Phase 4: ターゲット（仕様 8 対応）

### 4.1 ターゲット定義

* [ ] ターゲットを「音楽的オブジェクト」として定義する
* [ ] HP・攻撃力などのステータスを持たせない

---

### 4.2 配置

* [ ] 空間内に静的に配置する
* [ ] AI 思考・自律移動を実装しない
* [ ] 出現タイミングを拍イベントに同期させる

---

### 4.3 視線誘導

* [ ] プレイヤー想定視線方向に配置を偏らせる
* [ ] 明確な進行ルートを定義しない

---

## Phase 5: ロックオンシステム（仕様 5 / 10 対応）

### 5.1 ターゲットサイト

* [ ] 常時表示する照準 UI を作成する
* [ ] ロックオン成立時に視覚変化を行う

---

### 5.2 ロックオン条件

* [ ] 照準内に一定時間入ったターゲットを自動ロックオンする
* [ ] ロックオン数に上限を設けない

---

### 5.3 ロックオン音

* [ ] ロックオン成立時に短く小さい効果音を鳴らす
* [ ] 発射操作では音を鳴らさない

---

## Phase 6: 発射・攻撃生成（仕様 7 対応）

### 6.1 発射入力

* [ ] ボタン押下〜解放を検出する
* [ ] 解放時点でロックオン対象を確定する

---

### 6.2 攻撃生成

* [ ] 誘導レーザー的攻撃オブジェクトを生成する
* [ ] 生成時点では命中させない

**禁止**

* 入力と同時に命中させない

---

## Phase 7: 命中スケジューリング（仕様 7.3 中核）

### 7.1 基準拍決定（0.5拍閾値）

* [ ] 発射解放時刻を取得する
* [ ] 現在拍開始からの経過が 0.5拍未満の場合
  → 次の拍を基準拍とする
* [ ] 0.5拍以上の場合
  → 次の次の拍を基準拍とする

---

### 7.2 命中時刻算出

* [ ] 基準拍開始時刻を impactBaseTime とする
* [ ] 1拍を 1/2拍単位に分割する
* [ ] ロックオン順に命中時刻を割り当てる
* [ ] 命中時刻は絶対時間で算出する

**禁止**

* 拍イベントを待って命中処理を行わない
* 同時命中を発生させない

---

### 7.3 命中保証

* [ ] ロックオンされた攻撃は必ず命中させる
* [ ] ミス・空振りの概念を作らない

---

## Phase 8: 音程決定（仕様 7.4 / 追加合意）

### 8.1 音素材

* [ ] 離散音を使用する
* [ ] 1オクターブ内に制限する

---

### 8.2 音程選択

* [ ] 前回鳴った音程との差が小さい音を優先する
* [ ] 完全ランダム選択を行わない
* [ ] 結果として連続音／疑似和音的鳴りを形成する

---

### 8.3 再生条件

* [ ] 命中時のみ音を再生する
* [ ] 割り当てられた分割拍に同期させる

---

## Phase 9: ターゲット処理 VFX（仕様 8.3 / 9 対応）

### 9.1 処理方針

* [ ] ターゲットの消滅を禁止する
* [ ] 粒子へ分解する

---

### 9.2 残留表現

* [ ] 粒子を空間に残留させる
* [ ] 背景表現に統合する
* [ ] 拍イベントで再構成されるようにする

---

## Phase 10: ステージ完了（仕様 3.2 / 12 対応）

* [ ] すべてのターゲットが処理された状態を検出する
* [ ] BGM 終了と同時に体験を終了する

---

* [ ] スコアを実装しない
* [ ] HP・ダメージを実装しない
* [ ] ゲームオーバーを作らない
* [ ] 難易度分岐を作らない
* [ ] 複数ステージを作らない
* [ ] 成長・強化要素を作らない
